        Kelime defteri

          Claude bağlantısı

          Kelime anlamları, cümle çevirisi ve bölüm testleri Claude ile çalışır. Masaüstü uygulamasında bunun için bir Anthropic API anahtarı gerekir. Anahtarı console.anthropic.com adresinden oluşturabilirsin. API kullanımı claude.ai aboneliğinden ayrı ücretlendirilir.

          Anahtar Windows Kimlik Bilgileri Yöneticisi’nde saklanır, yalnızca Anthropic’e gönderilir. Anahtar olmadan da okuyabilir, kelimeleri dinleyebilir, defter tutup tekrar yapabilirsin.
